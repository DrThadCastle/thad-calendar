Privacy Policy – Thad Calendar (harryos)

Last updated: October 1, 2026

What this app is

Thad Calendar (harryos) is a private, single-user app for a personal assistant named "Thad". It runs on its owner's private server. It is not offered to the public.

Data accessed

The app signs in to one dedicated Google account that belongs to the assistant and requests the Google Calendar scope (https://www.googleapis.com/auth/calendar). With that access it:

  • reads calendars that the owner has explicitly shared with that account (read-only or free/busy), and
  • creates, updates, and deletes planning events only on that account's own "Thad Plan" calendar.

How data is used

Calendar data is processed on the owner's private server only to plan the owner's own time. Calendar content may be sent to the AI model provider(s) used to generate Thad's responses (currently OpenAI), solely to produce responses for the owner.

Storage and security

OAuth tokens are stored only on that private server and are readable only by the service account that runs the app.

Sharing

Data is not sold, not used for advertising, and not shared with anyone else.

Limited Use

Thad Calendar's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
